## 简介

本 Skill 提供通用的 PID 参数整定功能，支持任意电机控制场景。

### 核心特性

- **增量式 PID** - 更稳定的控制算法
- **符号自动映射** - 不受参数命名限制
- **用户确认机制** - 确保参数正确理解
- **默认参数配置** - 未提供的指标使用业界默认值
- **自动调参** - 根据性能指标自动搜索最优参数

## 快速开始

### 1. 触发 Skill

在 Claude Code 中输入：
```
PID调参
```

### 2. 提供电机参数

```
我的电机参数是: r=0.5, l=0.005, jm=0.001, b=0.0002, kt=0.3
```

### 3. 确认符号映射

Claude 会列出识别到的参数，等待你确认：

```
已识别以下变量:
┌──────────┬─────────┬─────────────────────┐
│ 符号     │  数值   │ 对应关系确认        │
├──────────┼─────────┼─────────────────────┤
│ r        │ 0.5     │ → Ra (电阻)? [Y/n]  │
│ l        │ 0.005   │ → Lq (电感)? [Y/n]  │
│ jm       │ 0.001   │ → J (转动惯量)? [Y] │
│ b        │ 0.0002  │ → B (阻尼)? [Y/n]   │
│ kt       │ 0.3     │ → Kt (转矩常数)? [Y]│
└──────────┴─────────┴─────────────────────┘
```

### 4. 提供目标性能（只需要目标转速）

```
目标转速: 1500 RPM
```

其余参数使用默认值。

### 5. 获取结果

Claude 会输出：
- 最优 PID 参数 (Kp, Ki, Kd)
- 响应曲线
- 性能指标

## 符号映射表

### 支持的参数别名

| 标准符号 | 别名列表 |
|---------|---------|
| **Ra** (电阻) | ra, r, res, resistance, r1, stator_resistance |
| **Lq** (q轴电感) | lq, l, lm, inductance, l_q, lq_inductance |
| **Ld** (d轴电感) | ld, ld_inductance |
| **J** (转动惯量) | j, jm, inertia, J_m, moment_of_inertia, rotor_inertia |
| **B** (阻尼系数) | b, damp, damping, friction, d, friction_coefficient |
| **Kt** (转矩常数) | kt, kt1, torque_k, tm, torque_const, torque_constant |
| **P** (极对数) | pp, poles, pole_pairs, p, number_of_poles |

### 示例映射

| 用户输入 | 映射后 |
|---------|--------|
| r=0.5 | Ra=0.5 |
| lq=0.01 | Lq=0.01 |
| inertia=0.001 | J=0.001 |
| friction=0.0001 | B=0.0001 |
| torque_k=0.2 | Kt=0.2 |
| pp=4 | P=4 |

## 性能指标

### 默认目标值

| 指标 | 默认值 | 说明 |
|------|--------|------|
| 上升时间 | < 3秒 | 从0到目标转速的时间 |
| 超调量 | < 2% | 峰值超过目标的百分比 |
| 稳态误差 | < 1% | 最终转速与目标的偏差 |
| 仿真时长 | 10秒 | 仿真总时间 |
| 电压上限 | 311V | 限幅保护 |

### 调参口诀

| 现象 | 调整方法 |
|------|---------|
| 上升太慢 | ↑Kp, ↑Ki |
| 超调过大 | ↓Kp, ↑Kd |
| 稳态误差大 | ↑Ki |
| 震荡频繁 | ↑Kd, ↓Kp |
| 电压波动大 | ↓Ki, ↓带宽 |

## 代码示例

### 直接调用核心模块

```python
from pid_tuning_core import auto_tune, IncrementalPID, MotorModel

# 方式1: 自动调参
result = auto_tune(
    J=0.001,           # 转动惯量
    B=0.0001,          # 阻尼
    Kt=0.2,            # 转矩常数
    Ra=1.0,            # 电阻
    Lq=0.01,           # 电感
    target_rpm=1500    # 目标转速
)

print(f"Kp={result['Kp']:.2f}, Ki={result['Ki']:.2f}, Kd={result['Kd']:.2f}")

# 方式2: 手动使用 PID 控制器
pid = IncrementalPID(Kp=20, Ki=80, Kd=2)
motor = MotorModel(Ra=1, Lq=0.01, J=0.001, B=0.0001, Kt=0.2)

for i in range(1000):
    u = pid.compute(target=157, measurement=motor.omega, dt=0.005)
    motor.step(u, dt=0.005)
```

### 参数解析示例

```python
from pid_tuning_core import identify_parameters

# 用户输入各种格式的参数
test_cases = [
    "Ra=1, Lq=0.01, J=0.001, B=0.0001, Kt=0.2",
    "r=0.5; lq=0.005; inertia=0.001; damping=0.0002; kt=0.3",
    "R=1.0, L=0.01, J=1e-3, B=1e-4, Kt=0.2",
]

for params in test_cases:
    confirmations, mapped = identify_parameters(params)
    print(f"输入: {params}")
    print(f"映射: {mapped}\n")
```
