# PID Tuning Skill

## Description

通用 PID 参数整定工具。通过对话确认用户提供的参数符号映射，执行增量式 PID 自动调参，输出最优控制参数和响应曲线。支持直流电机、PMSM、异步电机等场景。

## Triggers

- pid-tuning
- PID调参
- 调节PID

## Instructions

当用户请求 PID 调参时，按以下步骤执行：

### Step 1: 接收参数

接受用户以多种方式提供的参数：
- 直接输入：`Ra=1, Lq=0.01, J=0.001, B=0.0001, Kt=0.2`
- 文本片段：`r=0.5; l=0.005; inertia=0.001`
- 文件引用：`参数在 motor.py 文件中`

解析所有 key=value 形式的输入。

### Step 2: 符号映射确认（必须）

识别用户符号并列出对应关系：

```
已识别的参数:
  用户符号 → 标准符号 [确认?]
  ─────────────────────────
  r = 0.5   → Ra (电阻) [Y/n]
  l = 0.005 → Lq (电感) [Y/n]
  jm = 0.001 → J (转动惯量) [Y/n]
  b = 0.0002 → B (阻尼) [Y/n]
  kt = 0.3  → Kt (转矩常数) [Y/n]
```

等待用户确认或更正后再继续。

### Step 3: 目标性能

只要求用户提供目标转速，其他使用默认值：

```
目标转速: ___ RPM (必填)

可选指标 (直接回车使用默认值):
  上升时间 < ___ 秒 (默认 3秒)
  超调量 < ___ % (默认 2%)
```

### Step 4: 执行调参

使用增量式 PID 算法：

```
Δu[k] = Kp(e[k] - e[k-1]) + Ki·e[k] + Kd(e[k] - 2e[k-1] + e[k-2])
u[k] = u[k-1] + Δu[k]
```

自动调参策略：
1. 增大 Kp 直到开始超调
2. 添加 Ki 消除稳态误差
3. 添加 Kd 减小超调

### Step 5: 输出结果

输出：
- 最优 PID 参数 (Kp, Ki, Kd)
- 响应曲线图
- 性能指标（超调、上升时间、稳态误差、稳定性）
- 询问："是否满足要求？"

### 参数符号映射表

| 标准符号 | 别名 |
|---------|------|
| Ra | r, res, resistance |
| Lq, Ld | l, lm, inductance, l_q |
| J | jm, inertia, moment |
| B | b, damp, friction, D |
| Kt | kt, torque_k, tm |
| P | pp, poles, pole_pairs |

### 默认值配置

| 参数 | 默认值 |
|------|--------|
| 上升时间 | < 3秒 |
| 超调量 | < 2% |
| 稳态误差 | < 1% |
| 仿真时长 | 10秒 |
| 电压上限 | 311V |

## Notes

- 参数映射必须用户确认后才能继续计算
- 电压必须限幅保护硬件
- 未提供的性能指标使用默认值
- 优先保证稳定，再追求响应速度
